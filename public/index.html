How your data is handled

Memories and chat history are encrypted before database storage. The backend can decrypt them to answer questions. This is not end-to-end encryption.

Chat content enters your memory library only when you select Save to memory. Exports contain readable data. Provider backups may retain deleted records under their retention policy.

The sample preview keeps data only in this tab and clears it on reload.
