Privacy at a glance

Cloud mode encrypts memory content and chat history before database storage. The authorized backend can decrypt it for retrieval. This is not end-to-end encryption.

Conversations stay in chat history. They enter your library only when you select “Save to memory.”

The preview uses sample content held in this tab’s memory. It disappears when you reload. Please don’t use it for sensitive information.

Take your memories with you

Download the library and chat history as a JSON file.

Start fresh

Permanently remove saved memories and chat history. Cloud backups may retain older data under your hosting provider’s policy.

Beta limits: 200 memories, 3 MB per screenshot, and 20 chat questions per day. Account deletion is available through the project operator during beta.
